# Come-down(캄다운) API·테이블 책임 매핑

설계 v1.0 · 기존 구현을 기준으로 하지 않은 목표 책임이다. 원본은 architecture-map.json이며 API.md·ERD.md의 모든 항목과 대조해 생성한다. API/테이블을 추가하면 JSON을 갱신하고 문서를 다시 생성한다.

## HTTP API 책임

HTTP 책임은 Controller/보안 필터가 위치할 곳이다. 저장·계산 책임은 각 기능의 contract/application에 위임한다. experience 아래에 있다는 이유로 테이블 소유권을 가져가지 않는다. PUT /api/me/settings는 온보딩 단계에도 쓰이므로 experience.onboarding에 두되 저장된 계정의 설정 변경은 account에 위임하며 완료된 단계를 되돌리지 않는다. INITIAL/DAY28 CBI 제출은 experience.assessments가 cbi·safety·초기 온보딩 진행을 조합한다.

## OAuth·개발용 경로

사용자 API 39개와 구분한다. OAuth 콜백은 Spring Security 흐름으로 처리하며 임의의 중복 Controller를 추가하지 않는다. local 전용 시드/시계/삭제 기능은 운영 빈·라우팅에서 제외한다.

| 경로 | 책임 |
|---|---|
| `GET /oauth2/authorization/google` | shared.security + account + integration.google |
| `GET /oauth2/authorization/google-calendar` | shared.security + account + integration.google |
| `GET /login/oauth2/code/{registrationId}` | shared.security + account + integration.google |
| `POST /api/dev/login` | local 전용 개발 지원; shared.security 테스트 로그인(세션만 생성, 사용자 행은 만들지 않음) |
| `POST /api/dev/seed` | local 전용 개발 지원; 기능별 contract로 시드 입력 |
| `POST /api/dev/clock` | local 전용 개발 지원; shared.time의 테스트 시계 경계 |
| `DELETE /api/dev/data` | local 전용 개발 지원; experience.accountlifecycle의 정리 계약 사용 |

## 문서 대조 결과

API 39개와 테이블 18개가 누락/초과/중복 키 없이 매핑됐다. 이 검증은 문서의 책임 완전성 검사이며 실제 소스 구현·의존 방향·테스트 통과를 뜻하지 않는다.
